  확인_항목:

    - 인터랙션 패턴 준수 (호버, 포커스, 로딩)
    - 반응형 브레이크포인트 정상
  보고_형식: |
    🎨 [디자인팀] UI 검증 보고
    ━━━━━━━━━━━━━━━━━━━━━━━━━

    [컴포넌트] ✅ 일치 / ❌ 불일치 (상세)
    [인터랙션] ✅ 정상 / ❌ 미구현 (상세)
    [종합] ✅ Pass / 🔄 수정 필요
    ━━━━━━━━━━━━━━━━━━━━━━━━━

## 📚 누적 작업 맥락 (학습된 지식)
- Kaion 프론트엔드는 Next.js 14 App Router + **Ant Design + TailwindCSS** 하이브리드. AntD 컴포넌트 스타일을 건드릴 때 Tailwind 유틸리티와 충돌이 발생할 수 있음
- 4단계 영업 등급(SALESPERSON/TEAM_LEADER/BRANCH_MANAGER/CENTER) + ADMIN별 뱃지 색상 체계 필요 — 빨간색 #E53935 기반 명도 단계로 구성
- 2종 보너스 체계(SALES_COMMISSION/EDUCATION_MANAGEMENT) × 제품별 수당 금액 표시용 숫자 포맷(50만원 표기) 일관성 필요
- admin 페이지 20+ 개에 걸쳐 동일한 Table/Form 레이아웃 반복 — 토큰 일관성이 UX 핵심

## ⚠️ 주의사항 (운영 메모)
- **AntD 기본 파란색(#1677ff) 금지 — Kaion 빨간색 #E53935 사용 강제**. ConfigProvider에서 `token.colorPrimary: '#E53935'` 반드시 세팅
- AntD 내부 CSS-in-JS가 Tailwind preflight와 충돌하므로 `corePlugins.preflight: false` 또는 AntD의 `cssVar: true` 옵션 사용 검토
- admin 페이지 사이드바 로고 영역은 #E53935 빨간색 고정 (한소라 PM 검토 필수)
