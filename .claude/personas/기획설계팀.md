## 📚 누적 작업 맥락 (학습된 지식)

### 5단계 승급 조건 (정확한 값)
| 등급 | 승급 조건 |
|------|----------|
| MEMBER | 가입 시 기본 (누구나) |
| AGENT | 누적 PV ≥ **1,000,000** |
| MANAGER | 후원계보(sponsorId) **3팀** 형성 + **에이전트 15명** 육성 |
| BRANCH_CHIEF | 매니저 **3팀** 형성 + **매니저 4명** 육성 (각 팀 1명 이상) |
| DIVISION_CHIEF | 지부장 **3팀** 형성 + **지부장 5명** 육성 (각 팀 1명 이상) |
| ADMIN | 시스템 지정 (수당 대상 아님) |

### 6종 보너스 명세
| 보너스 | 금액 | 대상 | 조건 |
|--------|------|------|------|
| 판매 | **50만** (판매자 25 + 추천계보 상위 에이전트 25) | 전체 | 제품 판매 시 |
| 판매 관리 | **15만** | 직접 추천인 | 추천 회원 판매 시 |
| 판권 | 매니저 **10만** / 지부장 **18만** / 본부장 **24만** | 매니저 이상 | 직접 판매 시 |
| 판권 관리 | 매니저 **5만** / 지부장 **4만** / 본부장 **3만** | 동급 상위 | 동급 하위 회원 판매 시 |
| 공유 | **2만** (중복 지급) | 지부장/본부장 | 하위 판매 발생 시 |
| 지점 운영 | **5만** | 매니저 이상 | 세미나 진행 시 |

- 승급 이벤트는 `@nestjs/event-emitter`로 emit됨 (→ BullMQ 전환 예정, 박상훈과 협업)
- ADMIN은 수당 지급 대상 아님 — 보너스 계산 시 ADMIN 제외 로직 명세 필수

## ⚠️ 주의사항 (운영 메모)
- 승급 조건 숫자(100만 PV, 3팀, 15/4/5명)는 commission-prd + members README 둘 다와 **완전히 일치**해야 함 — 불일치 시 최윤아 PM 통해 동기화
- 6종 보너스 중 **공유 보너스는 중복 지급 가능**이므로 "최대 1회" 제약 명세 금지
- **완료 기준(Acceptance Criteria)은 김정훈(QA 리드)이 테스트 케이스로 전환할 수 있을 만큼 구체적이어야 함** — 모호한 "정상 동작" 금지
- `.bak` 된 `bonus-calculator.service.ts.bak` 등 4개 파일은 이전 기능 설계 시도 흔적 — 재설계 시 강민호 결정 필수
- 경계값 케이스(PV 999,999 vs 1,000,000, 팀라인 경계)는 QA팀 엣지 케이스로 반드시 전달
