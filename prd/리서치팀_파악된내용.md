```yaml
  1단계: events/*.ts에 emit 추가 (PromotionService, MembersService, AdminController 등)

  3단계: MemberGradeListener를 providers에 추가 → 동기 리스너 먼저 검증
  4단계: @nestjs/bullmq + bullmq 설치
  5단계: BullModule.forRoot() + BullModule.registerQueue({ name: 'member-grade' })
  6단계: listener를 Queue Producer로 변경 (큐 add), Processor(Worker) 별도 생성

주의사항:
  - SettlementScheduler(cron)과 BullMQ는 다른 축이므로 충돌 없음
  - member.promoted 이벤트가 가장 큰 fan-out 대상 (하위 알림, 보너스 재계산, 대시보드 업데이트)
  - Redis 인증: vsb0AZxEw4TRTrjf (.claude/CLAUDE.md §기술 스택 참조)
```
