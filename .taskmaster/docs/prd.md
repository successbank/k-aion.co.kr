## 3. 회원관리 시스템

### 3.1 회원 계층 구조

시스템은 5단계 계층 구조로 회원을 관리합니다. 각 등급별로 접근 가능한 기능과 권한이 다르게 설정됩니다.

> **v1.1 정정 (2026-04-15)**: schema.prisma의 MemberGrade enum과 일치하도록 등급명을 정정. 기존 5단계 계층 구조와 동일한 5개이나 명칭만 변경 (4단계 영업 + ADMIN system).

| 등급 | 권한 범위 | 주요 기능 |
|------|----------|----------|
| **관리자 (ADMIN)** | 전체 시스템 | 시스템 설정, 권한 관리, 전체 통계, 회원 승급 처리 |
| **센터 (CENTER)** | 본부 단위 | 본부 실적 조회, 지사장 관리, 본부 수당 확인 |
| **지사장 (BRANCH_MANAGER)** | 지부 단위 | 지부 실적 조회, 팀장 관리, 지부 수당 확인 |
| **팀장 (TEAM_LEADER)** | 팀 단위 | 팀원 관리, 팀 실적 조회, 개인 수당 확인 |
| **판매원 (SALESPERSON)** | 개인 | 개인 실적 조회, 주문, 개인 수당 확인 |

### 3.2 회원 등급별 대시보드 화면

관리자 (ADMIN)가 각 회원 등급별로 접근 가능한 메뉴와 기능을 설정합니다. 아래는 기본 화면 구성입니다.

#### 관리자 (ADMIN) 대시보드
- 전체 회원 현황 (등급별 분포, 신규 가입, 탈퇴)
- 전체 매출/수당 통계
- 권한 설정 관리 (등급별 메뉴 접근 제어)
- 시스템 설정 (수당률, 승급 조건 등)
- 회원 검색 및 상세 정보 조회

#### 센터 (CENTER) 대시보드
- 본부 실적 요약 (매출, 신규 회원)
- 산하 지부 현황
- 본부 수당 내역
- 지사장 (BRANCH_MANAGER) 실적 비교

#### 지사장 (BRANCH_MANAGER) 대시보드
- 지부 실적 요약
- 산하 팀장 (TEAM_LEADER) 현황
- 지부 수당 내역
- 팀장별 실적 비교

#### 팀장 (TEAM_LEADER) 대시보드
- 팀 실적 요약
- 팀원 현황
- 개인 수당 내역
- 팀원 실적 현황

#### 판매원 (SALESPERSON) 대시보드
- 개인 실적 요약
- 주문 내역
- 개인 수당 내역
- 제품 목록 조회

### 3.3 회원관리 기능 명세

| 기능 | 설명 | 접근 권한 |
|------|------|----------|
| 회원 등록 | 신규 회원 정보 입력 및 등록 | 관리자 (ADMIN), 센터 (CENTER), 지사장 (BRANCH_MANAGER), 팀장 (TEAM_LEADER) |
| 회원 수정 | 회원 정보 변경 | 관리자 (ADMIN), 해당 상위 관리자 |
| 회원 삭제/탈퇴 | 회원 비활성화 또는 탈퇴 처리 | 관리자 (ADMIN) |
| 등급 변경 | 회원 등급 승급/강등 | 관리자 (ADMIN) |
| 권한 설정 | 등급별 메뉴/기능 접근 권한 설정 | 관리자 (ADMIN) |
| 조직도 조회 | 계층 구조 시각화 | 전체 (본인 하위만) |

## 4. 제품관리 시스템

### 4.1 제품 카테고리 구조

제품은 2단계 카테고리로 분류됩니다.

1. **대분류**: 스킨케어, 헤어케어, 건강기능식품, 생활용품 등
2. **소분류**: 각 대분류 하위의 세부 카테고리

### 4.2 제품 정보 구성

| 항목 | 설명 | 비고 |
|------|------|------|
| 제품코드 | 고유 식별 코드 | 자동생성 |
| 제품명 | 제품 이름 | 필수 |
| 카테고리 | 대분류/소분류 | 필수 |
| 판매가 | 소비자 판매 가격 | 필수 |
| PV (Point Value) | 수당 계산용 포인트 | 필수 |
| 제품설명 | 상세 설명 | 선택 |
| 이미지 | 제품 사진 | 다중 업로드 |
| 재고수량 | 현재 재고 | 자동 차감 |
| 판매상태 | 판매중/품절/단종 | 필수 |

### 4.3 제품관리 기능

1. **제품 등록**: 새 제품 정보 입력 및 저장
2. **제품 수정**: 기존 제품 정보 변경
3. **제품 삭제**: 제품 비활성화 처리
4. **카테고리 관리**: 대분류/소분류 추가, 수정, 삭제
5. **재고 관리**: 재고 수량 조정, 재고 부족 알림
6. **제품 검색**: 이름, 코드, 카테고리별 검색

## 5. 수당관리 시스템

### 5.1 수당 유형

시스템은 다음 유형의 수당을 관리합니다. 세부 수당률과 조건은 관리자 (ADMIN)가 설정합니다.

| 수당유형 | 설명 | 대상 |
|---------|------|------|
| 직접판매 수당 | 본인이 직접 판매한 제품에 대한 수당 | 전체 회원 |
| 추천 수당 | 본인이 추천한 회원의 실적에 대한 수당 | 전체 회원 |
| 직급 수당 | 직급에 따른 하위 조직 실적 기반 수당 | 팀장 (TEAM_LEADER) 이상 |
| 리더십 수당 | 산하 조직 전체 실적에 대한 보너스 | 지사장 (BRANCH_MANAGER) 이상 |

### 5.2 수당 정산 프로세스

1. **실적 집계**: 일/주/월 단위로 판매 실적 자동 집계
2. **수당 계산**: 설정된 수당률에 따라 자동 계산
3. **검증**: 관리자 (ADMIN) 또는 담당자 검증
4. **확정**: 수당 내역 확정
5. **지급**: 지급 처리 (외부 시스템 연동 또는 수동)

### 5.3 수당관리 기능

- **수당 현황 조회**: 기간별, 유형별 수당 내역 조회
- **수당률 설정**: 수당 유형별 비율 설정 (관리자 (ADMIN))
- **수당 시뮬레이션**: 예상 수당 계산
- **수당 이력**: 과거 수당 지급 내역 조회
- **수당 리포트**: 엑셀 다운로드, 통계 차트
